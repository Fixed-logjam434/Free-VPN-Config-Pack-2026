## 🆘 Troubleshooting

### Connection fails or times out
- Check your internet connection first.
- Try a different server in the same region.
- Restart the app and try again.

### App won't install
- Make sure you have at least 100 MB free disk space.
- Temporarily disable antivirus software (some may block VPN installers) and retry.
- Run the installer as administrator (right-click → "Run as administrator").

### Slow connection
- Pick a server closer to your physical location.
- Try a WireGuard config instead of OpenVPN—it's faster.
- Close bandwidth-heavy apps like downloads or video streaming on other devices.
